# Style-file notice

`main.tex` uses the ICLR 2027 package interface (`iclr2027_conference`) and the ICLR page geometry, typography, anonymous title block, and author--year citation style.

The bundled `.sty`/`.bst` files are a local compilation copy so the project is self-contained. **Before submission, overwrite them with the exact files in the official ICLR 2027 style archive** linked from the ICLR 2027 Author Guidelines. Do not change margins, font sizes, spacing, or the official style implementation.

The manuscript is set to anonymous review mode. Add `\iclrfinalcopy` only for a camera-ready version.
